¿Qué es HTML, CSS y JavaScript?

HTML
Es el lenguaje de marcado que estructura el contenido de una página: define encabezados, párrafos, enlaces, imágenes y demás elementos, pero no cómo se ven ni cómo se comportan.
CSS
Es el lenguaje que se encarga de la presentación visual: colores, tipografías, distribución en pantalla y estilos en general, separado de la estructura que define HTML.
JavaScript
Es un lenguaje de programación que agrega comportamiento dinámico e interactividad a la página, permitiendo reaccionar a eventos y modificar el contenido en tiempo real.
